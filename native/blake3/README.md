# Embedded BLAKE3 build

This private `cdylib` wraps the official Rust BLAKE3 1.8.7 crate at commit
`f3149ec5bb5449af877ba20377a11008ff499fa2`. Cargo resolves only the locked,
vendored sources in `vendor/`; the wrapper enables `wasm32_simd` with no
allocator and no standard library.

The generated adapter artifact reserves two fixed Wasm pages (128 KiB). A
64 KiB explicit stack, one 16 KiB input staging buffer, one 32 byte result
buffer, and module-owned `Hasher` state fit inside that reservation. The only
host-facing functions are the input/output accessors, `init`, bounded `update`,
and `finalize`. The host creates a new Wasm instance for every operation.

From the repository root, `npm run build:blake3:wasm:update` intentionally
rebuilds and records the inline artifact and manifest. `npm run
build:blake3:wasm` performs two clean offline builds and verifies the checked-in
bytes, module shape, fixed memory, and source/toolchain manifest. The build
script remaps checkout paths in compiler diagnostics so the generated bytes
remain identical across checkout locations.
